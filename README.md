AI Code Review Studio 🚀

An advanced AI-powered Code Review Platform built using the MERN Stack with intelligent review analysis, security detection, performance suggestions, review history tracking, authentication, analytics dashboard, and modern UI/UX.

This project helps developers improve code quality by automatically analyzing source code and generating structured feedback using AI models.
